      Printing tips (Brother P-touch Editor, 24 mm tape)

      1. Select your printer and 24mm tape in P-touch Editor, then import the PNG with Image.
      2. The editor imports the PNG far too small. Select the image in the Layout panel, keep Fix Aspect Ratio on and type Height = 18 mm. The width follows, so the label gets its real length.
      3. Set Y to 3 mm to centre the artwork on the tape (18 mm print area on 24 mm tape) and leave Set Length off.
